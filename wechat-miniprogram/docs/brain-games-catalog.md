# 脑力训练游戏清单（类舒尔特方格）

> 适用项目：心智探索局（微信小程序）
> 用途：为新增「训练」Tab 提供游戏选型与实现依据
> 说明：以下游戏均改编自成熟的认知心理学范式，**仅作娱乐/自我探索/训练热身用途，不构成任何医学诊断或专业能力评估**。
> ✅ **状态：全部 31 个游戏已落地**（5 个认知维度齐全），实现位置 `wechat-miniprogram/games/<id>/`，详见 README「已落地游戏」表与 `utils/game-registry.js`。

---

## 通用设计约定

每个游戏在代码中以独立 `Component` 实现，统一契约（详见开发计划）：

```
games/<id>/index.js 暴露:
{ id, name, dim, icon, color, desc,
  levels,            // 难度档（如 3x3~9x9、N 级数）
  generate(level),   // 生成关卡数据（纯函数，便于单测）
  score(state),      // 计算成绩 { time, errors, score, ... }
  reference }        // 范式来源/文献
```

成绩记录：`ma_train_<id>`（最佳/均值/历史，上限同 `ma_history`），趋势图复用 `utils/trend.js`。

## A. 注意力 / 视觉搜索

### A1 舒尔特方格（Schulte Grid）★首批
- **范式来源**：国际通行视觉定向搜索训练（shuertefangge.com / App Store 多款同类）
- **认知维度**：视觉搜索速度、视幅拓展、专注集中度、抗干扰
- **玩法**：N×N 网格随机填入 1~N²，按 1→N² 顺序尽快点选；可选数字/字母/古诗模式、反向（N²→1）、限时模式
- **难度**：3×3 / 4×4 / 5×5 / 6×6 / 7×7 / 8×8 / 9×9
- **实现要点**：网格用 `view` 九宫格 + flex 布局；点错震动 `wx.vibrateShort`；记录用时、错误数、最佳成绩；复用 `utils/color.js`
- **参考**：https://shuertefangge.com/ 、https://schulte.top/

### A2 数字划消（Cancellation）
- **范式来源**：临床注意力持续操作常用任务
- **认知维度**：视觉分辨、持续注意、细心度
- **玩法**：在字符矩阵中划掉指定目标（如所有"0"、指定形状），计时并统计漏划/误划
- **难度**：网格密度、干扰项比例、目标数量
- **实现要点**：长按/点击标记消除；错误=未消目标或错消非目标

### A3 视觉搜索 / 找不同（Visual Search）
- **范式来源**：focus-game.org 视觉搜索任务
- **认知维度**：选择性注意、扫视效率
- **玩法**：从多个干扰项中找出与样例一致/不同的目标（颜色/形状/方向）
- **难度**：干扰项数量、相似度
- **实现要点**：`utils/figure.js` 绘制图形单元，复用色盲纹理冗余通道

### A4 按要求找方格 / 找几何位置
- **范式来源**：shuertefangge.com「按要求找方格」「找几何位置」
- **认知维度**：选择性注意、规则遵循
- **玩法**：按条件（颜色/形状/行列位置）点选符合条件的格子，如"点所有红色圆"
- **难度**：条件组合数、网格大小

### A5 图形追踪（Figure Tracking）
- **范式来源**：河南健康网注意力训练（图形追踪）
- **认知维度**：视觉追踪、运笔稳定
- **玩法**：沿数字轨道从 1 追踪到 N，眼随手动，计时
- **实现要点**：canvas 连线绘制轨迹

### A6 数字迷宫 / 镜像沙漏 / 数字密码
- **范式来源**：shuertefangge.com 同类专注小游戏
- **认知维度**：注意 + 记忆 + 顺序
- **玩法**：数字迷宫=按顺序连数字走出迷宫；镜像沙漏=镜像/对称判断；数字密码=记忆+顺序回溯

## B. 工作记忆

### B1 N-Back（双重 N-Back）★可选首批
- **范式来源**：Jaeggi et al. (2008) 工作记忆训练范式
- **认知维度**：工作记忆更新、中央执行
- **玩法**：序列呈现位置/声音，判断当前刺激是否与 N 步前相同；双模态=视觉位置+听觉字母
- **难度**：N=1~3，序列长度
- **实现要点**：计时器逐帧呈现；需音频 `wx.createInnerAudioContext` 或振动编码

### B2 记忆配对（Memory Match / 翻牌）
- **范式来源**：FreeFocusGames 记忆配对
- **认知维度**：视觉短时记忆、注意力
- **玩法**：翻牌找成对（图形/字母/数字主题），最少步数/最短时间
- **难度**：牌数（4~24 对）、主题
- **实现要点**：卡片翻转动画；记录步数、用时、连击

### B3 方块/图形记忆（Pattern Memory）
- **范式来源**：FreeFocusGames 方块记忆挑战
- **认知维度**：视觉序列记忆
- **玩法**：方块依次闪烁，复现闪烁顺序
- **难度**：方块数、序列长度

### B4 序列记忆 Simon（西蒙说）
- **范式来源**：经典 Simon 游戏
- **认知维度**：序列记忆、听觉-视觉绑定
- **玩法**：重复不断增长的颜色/声音序列
- **难度**：序列增长率

### B5 数字广度（Digit Span）
- **范式来源**：韦氏/瑞文常用分量表范式
- **认知维度**：语言工作记忆广度
- **玩法**：顺背（复述）与倒背（逆序复述）数字串
- **难度**：长度递增

### B6 科西方块（Corsi Block）/ 数箱子
- **范式来源**：Corsi 空间记忆范式
- **认知维度**：空间序列记忆
- **玩法**：点击方块序列后复现（Corsi）；3D 立方体出现消失后计数（数箱子）
- **难度**：方块数、序列长度

## C. 反应 / 处理速度

### C1 反应时间（Reaction Time）★可选首批
- **范式来源**：reactiontester.com
- **认知维度**：简单反应时、处理速度
- **玩法**：屏幕变绿后尽快点击，记录平均 RT 与稳定性
- **难度**：随机延迟、试次
- **实现要点**：`Date.now()` 计时；统计均值/标准差

### C2 斯特鲁普（Stroop）★首批
- **范式来源**：Stroop (1935) 经典色词任务
- **认知维度**：抑制控制、冲突监控、选择性注意
- **玩法**：识别墨水颜色而非词义（如红字"绿"→点红色）；一致/冲突试次对比
- **难度**：试次、是否限时
- **实现要点**：记录 RT、正确率、干扰效应（冲突-一致差）

### C3 Flanker 侧抑制（Eriksen Flanker）
- **范式来源**：Eriksen & Eriksen (1974)
- **认知维度**：选择性注意、干扰过滤
- **玩法**：中央箭头方向判断，忽略两侧干扰箭头
- **难度**：干扰一致性比例

### C4 打地鼠 / Go-NoGo
- **范式来源**：reactiontester / Go-NoGo 范式
- **认知维度**：反应抑制、冲动控制
- **玩法**：地鼠出现前击打（打地鼠）；仅对目标刺激响应、对干扰抑制（Go-NoGo）
- **难度**：出现频率、干扰比、时长

### C5 颜色匹配冲刺 / 西蒙说 / 更大数字挑战 / CPS
- **范式来源**：FreeFocusGames / reactiontester
- **认知维度**：处理速度、冲动控制
- **玩法**：点击文字颜色（颜色匹配）；仅当指令含"Simon Says"才执行（西蒙说）；快速选更大数字；单位时间连点计数（CPS）

### C6 双重决策（Double Decision）
- **范式来源**：BrainHQ 有用性注意范式
- **认知维度**：分配注意、Processing Speed
- **玩法**：短暂呈现中判断中央目标并定位周边路牌
- **难度**：区域数、呈现时长

## D. 放松 / 正念

### D1 箱式呼吸（Box Breathing）★首批
- **范式来源**：美国海豹突击队/急救人员呼吸技术
- **认知维度**：自我调节、平静专注、HRV
- **玩法**：吸气 4s→屏息 4s→呼气 4s→屏息 4s 循环，动画引导
- **实现要点**：canvas/SVG 方块动画 + 计时；记录完成轮数/时长

### D2 4-7-8 呼吸法 / 共振呼吸（6 次/分）
- **范式来源**：Weil 4-7-8 法；共振呼吸迷走神经调节研究
- **认知维度**：放松、焦虑缓解
- **玩法**：吸气 4s→屏息 7s→呼气 8s；或每分钟 6 次节律引导

### D3 正念呼吸引导
- **认知维度**：正念觉察、专注复位
- **玩法**：跟随引导语与节奏呼吸，适合训练前热身/工作间隙
